# Altyapı (1. aşama) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the `develop` branch, build a Next.js + Payload CMS app that recreates the Eserler, Kitaplar and home pages of the static design. The data comes from a local Postgres. The app is multilingual (tr/en/ar) and never queries the database on a visitor request.

**Architecture:**
- **App and data:** Payload 3 runs inside the same Next.js app. Pages are statically generated per locale and read data through tag-cached Local API getters. Payload hooks invalidate those tags on save and then warm up the affected URLs.
- **Routing:** Middleware maps public localized paths (`/eserler`, `/en/works`, `/ar/works`) onto internal `[locale]/<key>` routes.
- **Seed:** An idempotent seed reads the existing `tasarim/*.js` data files.

**Tech Stack:** Next.js (the version the Payload template ships), Payload 3, `@payloadcms/db-postgres`, `@payloadcms/storage-vercel-blob` (inactive without a token), TypeScript, Vitest, pnpm, Node 24, PostgreSQL 18 (local).

**Spec:** `docs/superpowers/specs/2026-11-07-altyapi-design.md`

## Global Constraints

- **Locales:** `tr` (default), `en`, `ar` (rtl). Payload `localization.fallback: true`. Missing translations show the Turkish text.
- **Public paths:**
  - tr: `/`, `/eserler`, `/kitaplar`
  - en: `/en`, `/en/works`, `/en/books`
  - ar: `/ar`, `/ar/works`, `/ar/books`
- **Database at runtime:** No database query on a visitor request. Queries happen only on admin use, seed, build, and regeneration after a save.
- **No time-based revalidation.** Invalidation is tag-based only.
- **Media URLs:** Never served through Payload's `/api/media/file/*` route, because it hits the DB.
  - Local: `upload.staticDir = public/media` and URL `/media/<filename>`.
  - Blob: `disablePayloadAccessControl: true`, direct blob URL.
- **Placeholder text:** Empty info fields render the UI string `bilgiGirilecek` ("Bilgi girilecek").
- **Look:** The visuals must match `tasarim/` (light/dark, 1280 and 375 widths). Copy CSS from `tasarim/` rather than rewriting it.
- **Theme:** localStorage key `tema`, values `light`/`dark`, set on `<html data-theme>` before first paint.
- **Unbuilt pages:** Links to Yazılar, Videolar, Hayatı, İletişim and yazı detail go to `/tasarim/<name>.html`, which is a script-made copy of `tasarim/` under `public/tasarim/` and is gitignored.
- **Not yet in the CMS:** The home page sections İcazet, Yazılar, Video, Dersler and Hayatı stay as static Turkish JSX in this phase.
- **Seed languages:**
  - UI strings are seeded in tr, en and ar.
  - Works, books and home headings are seeded in Turkish only.
- **Environment:**
  - Env vars: `DATABASE_URL`, `PAYLOAD_SECRET`, `BLOB_READ_WRITE_TOKEN` (optional), `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `NEXT_PUBLIC_SITE_URL`.
  - `.env.example` is committed and `.env` is not.
- **Deploys:** `develop` is not deployed: `vercel.json` sets `git.deploymentEnabled.develop = false`.
- **Commits:**
  - Write commit messages in Turkish.
  - No "Claude" and no `Co-Authored-By` line anywhere in commits.
  - Stage files by name, and never stage `.claude/`.
- **Admin UI language:** Turkish (`@payloadcms/translations` `tr`).

## Review Focus

1. **Turkish characters and apostrophes in titles** (`Şey'en Lillâh`, `Mesnevî'de Geçen Hikâyeler`) must produce stable, unique, ASCII slugs. Two works with the same title get `-2`. *Test in Task 2.*
2. **A work with no Turkish-only fields filled** (no year, no description) must render without "undefined" or empty separators in the meta line or the lightbox. *Test in Task 7.*
3. **Deleting an item** (not just editing it) must invalidate and rewarm the same pages. *Test in Task 3.*
4. **Unknown or prefixed paths:**
   - `/tr/eserler` redirects (308) to `/eserler`.
   - `/en/eserler` and `/fr` are 404.
   - `/admin` and `/api` are never rewritten.
   *Test in Task 4.*
5. **Re-running the seed** after an admin edited a seeded work must not create duplicates. It updates by slug. *Test in Task 5.*
